我们开发了一个网易云音乐网页版用户脚本：网易云音乐歌单排序。这个脚本目前已经上传到 [GitHub 源码仓库](https://github.com/Harmonese/ncm-playlist-sort-and-move) 和 [Greasy Fork](https://greasyfork.org/zh-CN/scripts/593501-%E7%BD%91%E6%98%93%E4%BA%91%E9%9F%B3%E4%B9%90%E6%AD%8C%E5%8D%95%E6%8E%92%E5%BA%8F)，现已开启 Beta 测试。它面向网易云音乐网页版歌单管理场景，希望给歌单增加更灵活的排序、批量移动和批量删除能力。

## 脚本作用

脚本面向需要经常在网易云整理大体量歌单的用户。网易云音乐歌单一旦曲目数量变多，手动调整顺序就会变得很痛苦。尤其是考虑到移动端频繁调整用户界面且歌单排序体验并无改善、网页版本身缺乏原生排序功能时，这个用户脚本会变得很实用。

目前脚本已经能够覆盖常见的歌单排序方案：

- 按歌曲标题排序；
- 按歌手排序；
- 按发行日期排序；
- 按热度指标排序；

同时还实现了批量歌曲管理中非常重要的几个功能：

- 按序号区间批量移动歌曲；
- 按序号区间批量删除歌曲；
- 在排序、移动或删除后尝试恢复上一次操作前的歌单顺序。

其中标题和歌手排序会考虑不同文字体系的比较顺序，包括拉丁字母、汉字、日文假名、韩文、西里尔字母、希腊字母、阿拉伯字母、数字和其他字符等。发行日期排序则适合用来整理专辑、作品年表或按照发布时间维护的歌单。

脚本目前处在 Beta 测试阶段。大部分的功能已经能够稳定运行，但是仍然可能存在漏洞。虽然我们提供撤回上次更改功能，但是对于新用户而言，熟悉操作逻辑的过程仍然可能导致现有歌曲丢失，因此我们建议使用时先使用测试歌单验证排序效果，再在目标歌单使用。

## 如何使用

你需要先安装浏览器用户脚本管理器，例如 Tampermonkey 或 Violentmonkey，然后通过 Greasy Fork 页面安装：

- [Greasy Fork：网易云音乐歌单排序](https://greasyfork.org/zh-CN/scripts/593501-%E7%BD%91%E6%98%93%E4%BA%91%E9%9F%B3%E4%B9%90%E6%AD%8C%E5%8D%95%E6%8E%92%E5%BA%8F)

源码、问题反馈和开发记录可以查看 GitHub 仓库：

- [GitHub：Harmonese/ncm-playlist-sort-and-move](https://github.com/Harmonese/ncm-playlist-sort-and-move)

我们欢迎大家在 Beta 阶段参与测试，尤其是反馈这些问题：

- 不同规模歌单的排序是否稳定；
- 中文、英文、日文、韩文等混合标题排序是否符合预期；
- 按发行日期排序时，专辑内曲目顺序是否合理；
- 批量移动和批量删除是否存在边界情况未被脚本功能覆盖；
- 网易云音乐网页版不同页面状态下，脚本按钮是否能正常出现；
- 是否有浏览器或用户脚本管理器兼容性问题。

脚本目前只在 Tampermonkey 和 Violentmonkey 上做过初步测试，但应当兼容绝大部分常见的脚本管理器。

如果遇到问题，可以在 GitHub 仓库提交 Issue，也可以通过本站提供的联系方式告诉我们。
