## 乐队简介

簡諧點源（Harmonese）是一支中国的电子音乐组合，由 **聲爆光年** 及 **概率雲實體** 联手创立，于 2021 年正式成立。

### 核心成员

- **聲爆光年** ：作曲、作词、制作及人声担当，是簡諧點源音乐的核心创作者。

- **概率雲實體** ：负责视觉创意与封面设计，共同构筑簡諧點源的视觉美学。

我们经常与其他音乐人、混音师及艺术家进行合作。

### 音乐风格

我们的音乐核心建立在 **电子音乐（Electronic）**、**合成器浪潮（Synthwave）**、**迷幻舞曲（Trance）** 等流派之上，受到了 **赛博朋克（Cyberpunk）** 风格的深刻影响。

## 软件项目

我们所开发的软件项目基本来自项目成员所遇到的创作与发行需求：整理歌词、同步时间轴、维护音乐元数据、制作网页归档，以及把反复出现的手工流程变成可以复用的工具。

本站并不长期维护各项目的完整安装手册与参数索引。最新用法、发行版、问题反馈和开发文档以 GitHub、PyPI 或项目 README 为准。但本站会记录这些工具的一些开发足迹、核心功能和重大版本更新。

### 主要项目

- **[Rolling Pebble](https://github.com/Harmonese/rollingpebble)**：由 akri/lrc-maker 所启发的一个功能较为完整的本地歌词工作站，用于处理与维护 LRC 歌词，并把滚动歌词编辑、打轴、检查与整理上传流程集中到一个本地应用中。

- **[pylrclib](https://github.com/Harmonese/pylrclib)**：围绕 LRCLIB 的 Python 工具与命令行项目，用于歌词搜索、下载、清理与发布等流程。

- **[py-roller](https://github.com/Harmonese/py-roller)**：滚动歌词自动生成工具，用于根据音频与歌词生成、对齐并导出可用于展示、后期制作或流媒体数据库的滚动歌词素材。

- **[harmonese-site](https://github.com/Harmonese/harmonese-site)**：本站源码。这里保存网站结构、文章归档、资源规范与部署配置，是我们长期维护官方资料入口的基础设施。
